# Ginsberg Center Community Partner Map

An interactive Shiny web application that maps the University of Michigan Ginsberg Center for Community Service and Learning's community partner network, allowing users to explore partner organizations and their matched student projects.

---

## Features

- **Interactive map** — 372 geocoded community partner organizations displayed as clustered markers
- **Organization details** — click any marker to view the organization's address, focus areas, description, and partner status in the sidebar
- **Matched projects** — each organization's sidebar panel lists all matched FY25 and FY26 student initiatives, including the resource offering, category, and completion date
- **Focus area filter** — multi-select listbox to highlight organizations by one or more focus areas; unmatched organizations are dimmed on the map
- **Partner status filter** — radio button to filter the map to Active partners, Leads, or all organizations
- **Reset view button** — snaps the map back to the default zoom and center with one click

## Data

### Source file: `Mapping CP Network.xlsx`

| Sheet | Contents |
|---|---|
| `Accounts with categories` | Raw organization records exported from Salesforce, including billing address, partner status, and category tags |
| `FY25` | Matched student projects for fiscal year 2025 |
| `FY26` | Matched student projects for fiscal year 2026 |

### Processed file: `Accounts_wideCategories_Geocoded.csv`

Generated by `data_processing.R`. Each row is a unique organization with:
- Billing address fields
- Focus area categories pivoted to wide format (`Category.1` through `Category.9`)
- Geocoded latitude and longitude (via ArcGIS through `tidygeocoder`)

## Setup

### Prerequisites

- R (≥ 4.4.0)
- The following R packages:

```r
install.packages(c("shiny", "bslib", "leaflet", "dplyr", "readxl", "tidyr", "htmltools"))
```

For running the data processing script, also install:

```r
install.packages(c("tidygeocoder", "readr", "stringr"))
```

### Running the app

Open `app.R` in RStudio and click **Run App**, or run from the console:

```r
shiny::runApp()
```

The app reads directly from `Accounts_wideCategories_Geocoded.csv` and `Mapping CP Network.xlsx` — no additional setup is needed as long as those files are present.

---

## Data Processing

`data_processing.R` is a **one-time setup script** and does not need to be re-run unless the source data changes. It:

1. Reads the `Accounts with categories` sheet from `Mapping CP Network.xlsx`
2. Pivots multiple category tags per organization into a wide format
3. Constructs a full address string from billing address fields
4. Geocodes each address using the ArcGIS provider via `tidygeocoder`
5. Writes the result to `Accounts_wideCategories_Geocoded.csv`

> **Note:** Geocoding can take several minutes depending on the number of records. The geocoding step is intentionally left commented out in the script to prevent accidental re-runs.
